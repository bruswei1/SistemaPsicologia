## 📋 NOTAS IMPORTANTES

1. **El EXE es un wrapper**
   - El EXE es un pequeño ejecutable (1.2 KB) que lanza el JAR
   - Requiere Java instalado en el sistema
   - Requiere MySQL ejecutándose

2. **Puedes distribuirlo**
   - Copia el archivo SistemaPsicologia.exe a donde quieras
   - Funciona en cualquier carpeta
   - No necesita configuración adicional

3. **Si tienes problema al ejecutar**
   - Verifica que Java esté instalado: `java -version`
   - Verifica que MySQL esté corriendo: `docker ps`
   - Ejecuta como Administrador si es necesario
   - Revisa los logs de la consola

---

## 🔧 SOLUCIÓN DE PROBLEMAS

❌ **"Cannot find Java"**
→ Instala Java desde: https://www.oracle.com/java/

❌ **"No se puede conectar a MySQL"**
→ Ejecuta: `docker-compose up -d`

❌ **"No se encuentra el archivo JAR"**
→ Verifica que SistemaPsicologia.jar esté en la misma carpeta

❌ **"Access Denied"**
→ Ejecuta como Administrador
